# Packet 32f: fix five review findings on the mutation engine (PR 142)

Read `.handoff/packets/30-mutation-architecture.md`. Base = the PR 142 branch. Every fix is **fail closed**: when the code cannot be certain, the link becomes `unsupported`/the item is skipped. Add one named regression per finding. Files: `living-spec/src/mutation/subject.rs`, `generate.rs`, tests.

1. **External-module exclusion ignores inline ancestry.** `mod outer { #[cfg(test)] mod helper; }` excludes `src/helper.rs` instead of `src/outer/helper.rs`, so test helpers become production subjects. Simplest safe rule: if any `mod name;` (external) declaration appears inside an inline `mod { }` block, or an inline module is itself `#[cfg(test)]` and contains an external declaration, mark the whole package `unsupported: nested external modules`. Regression `external_module_under_inline_cfg_test_module_unsupported`.
2. **Quoted TOML keys bypass containment** (`external = { "path" = "/outside" }`). Conservative: in any dependency table (including inline tables), if the text contains a quoted key (`"` or `'` immediately before `=` or a quoted `path`/`git`/`workspace` token), return `unsupported: dependencies outside crate`. Regressions `quoted_path_key_unsupported`, `quoted_git_key_unsupported`, `quoted_workspace_key_unsupported`.
3. **`extern "C" fn` slips past the attribute scans** so `#[cfg(test)] extern "C" fn helper()` is a subject. Skip every `fn` whose qualifiers include `extern` (with or without an ABI string), `unsafe`, `async`, `const`, or `default` — only plain `fn`/`pub fn`/`pub(crate) fn` are candidates; make both backward scans handle `extern "abi"` anyway. Regression `cfg_test_extern_fn_never_a_subject`.
4. **Qualified associated-function calls are mistaken for free-function calls** (`Counter::value()` resolving to a free `value`). Only accept a call as a free-function call when it is a bare `name(...)`, or a path whose segments before the name are all lowercase module-style idents (`crate`, `self`, `super`, `a::b`). If any segment before the name starts with an uppercase letter (type or trait path), or the path is a turbofish or `<T as Trait>::` form, the call is not a subject. Regression `associated_function_call_not_a_free_subject` with a free `value()` and `Counter::value()` delegating to it.
5. **Scientific-notation literals are split by the lexer** (`1e+3` => `1`, `e`, `+`, `3`) so the exponent sign and digits get mutated. In `generate.rs`, before selecting sites, mark as non-mutable every token that is part of a numeric literal run: a number token adjacent (no whitespace) to an identifier starting with `e`/`E` or `_`/letter suffix, the `+`/`-` right after such an `e`, and the digits after it. Also keep skipping hex/binary/octal/suffixed/underscored forms. Regressions `positive_exponent_literal_not_mutated`, `negative_exponent_literal_not_mutated`.
